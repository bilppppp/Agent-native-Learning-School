## 零花钱账本里的正负抵消

有了正数和负数，我们就要学会怎么把它们算起来。

很多刚接触负数的同学，看到算式里一堆加号和减号就容易发晕。其实，如果把它放进生活场景，规则会变得非常自然。

想象你的小账本：
- **存入（正数）**：$+\text{元}$
- **支出（负数）**：$-\text{元}$

### 1. 同号相加：累积效果
- 如果你昨天借了小明 $3$ 元，今天又借了他 $2$ 元，你一共欠了他多少钱？  
  算式：$(-3) + (-2) = -5$。  
  **法则**：同号两数相加，取相同的符号，并把绝对值相加（$3 + 2 = 5$）。

### 2. 异号相加：互相抵消
- 如果你今天卖废品赚了 $5$ 元（$+5$），随后买了一支圆珠笔花了 $3$ 元（$-3$），你手里还剩多少钱？  
  算式：$(+5) + (-3) = +2$ 元。  
- 如果你只赚了 $3$ 元（$+3$），但看中了一本科普书花了 $5$ 元（$-5$），结果是你的钱包亏空了 $2$ 元：  
  算式：$(+3) + (-5) = -2$ 元。  
  **法则**：绝对值不相等的异号两数相加，取绝对值较大的加数的符号，并用较大的绝对值减去较小的绝对值（$5 - 3 = 2$）。

## 为什么“减去一个负数”等于加上正数？

这是初一数学最经典的一个弯儿：为什么 $3 - (-3)$ 会变成 $3 + 3 = 6$？

我们来看最直观的**温差问题**：
白天最高气温是 $3^\circ\text{C}$，夜间最低气温是 $-3^\circ\text{C}$。

问：白天比夜间高了多少度？
1. 从温度计上看，从 $-3^\circ\text{C}$ 升到 $0^\circ\text{C}$ 需要上升 $3^\circ\text{C}$；
2. 再从 $0^\circ\text{C}$ 升到 $3^\circ\text{C}$ 又需要上升 $3^\circ\text{C}$；
3. 一共上升了 $3 + 3 = 6^\circ\text{C}$！

而在数学中，“高了多少”是用减法算的：$\text{最高温度} - \text{最低温度}$。
所以：
$$3 - (-3) = 6$$

这就是著名的**有理数减法法则**：
> **减去一个数，等于加上这个数的相反数。**
> $$a - b = a + (-b)$$

减去 $-3$，相当于加上 $-3$ 的相反数 $+3$。拿掉一笔“债务”，其实就等于给你增加了一笔“财富”！
