←──●──┬──┬──●──┬──┬──●──→

这里 **0 是原点**，向右是正方向，相邻刻度之间是 **1 个单位长度**。

按照教材的定义，**绝对值就是一个数对应的点到原点的距离**。

- −3 在 0 左边，离 0 有 **3 格**，所以 **|−3| = 3**。
- +3 在 0 右边，也离 0 有 **3 格**，所以 **|+3| = 3**。

用温度理解：−3℃和 +3℃都与 0℃相差 3 度，**但温度并不相同**。绝对值只看“离零多远”，不看“零上还是零下”。这两个数也互为**相反数**。
